# Guía rápida de Moni

**Una idea:** tu dinero está en **cuentas**; cada cuenta se divide en **bolsillos** (casa, mercado, ocio…). Cada peso que entra o sale se anota en un bolsillo, y los saldos se calculan solos.

**Cómo se ordena:** cuatro secciones según lo que quieres hacer. **Mi dinero** (bolsillos, movimientos, ahorro, inversiones), **Pagos** (servicios, tarjetas, créditos), **Planear** (presupuesto, ingresos, metas, lista de deseos) y **Analizar** (análisis, vista anual, calculadora). En el celular son las pestañas de abajo (Analizar está dentro de Planear); en el computador, la barra lateral.

## Lo de cada día
| Quiero… | Hago… |
|---|---|
| Anotar un gasto | El botón **+** (o **Registrar**) → *Gasto*: valor, si suma a tus saldos, concepto y bolsillo |
| Anotar un ingreso | El botón **+** → *Ingreso* |
| Mover dinero de un bolsillo a otro | El botón **+** → *Mover* |
| Ver cuánto queda | **Mi dinero → Bolsillos** |
| Pagar la luz, el agua, Netflix… | **Pagos → Servicios** (o *Pagar servicios* en Inicio) → toca el cobro → *Registrar el pago* |
| Me equivoqué | Toca **Deshacer** en el aviso, o anula el movimiento desde su detalle |

## Lo de cada mes
1. **Planear → Presupuesto → Generar** el mes desde tu plantilla (entran solos tus servicios, suscripciones y metas).
2. **Planear → Ingresos → Nómina → Registrar** lo que te llegó y repartirlo a tus bolsillos.
3. **Pagos → Tarjetas** → tarjeta → **Pagar extracto**; **Pagos → Créditos** → crédito → **Pagar cuota**.
4. **Planear → Metas** → *Aportar* lo de este mes a cada meta (o márcalo desde su renglón del presupuesto).
5. **Mi dinero → Bolsillos → Cuadrar** cada cuenta con lo que dice tu banco.

## Más cosas (detalle en el [Manual](MANUAL_USUARIO.md))
| Quiero… | Hago… |
|---|---|
| Ver en qué gasto y cómo evoluciona mi dinero | **Analizar → Análisis**, y los gráficos de Inicio, Movimientos, Presupuesto y cada módulo |
| Ahorrar para algo (Navidad, un viaje, la moto) | **Planear → Metas → +**: cuánto, para cuándo y en qué bolsillo; ajusta el *Plan por mes* |
| Anotar lo que quiero regalar o comprarme | **Planear → Lista de deseos → +** (con lluvia de ideas) |
| Llevar mis acciones, ETF o cripto | **Mi dinero → Inversiones → +**: búscala por nombre o símbolo |
| Anotar un CDT | **Mi dinero → Inversiones → CDT** |
| Anotar otro ingreso (arriendo, otro trabajo) | **Planear → Ingresos → Otros ingresos** |
| Calcular un préstamo o cuánto ahorrar | **Analizar → Calculadora** |
| Tener una cuenta en dólares | Crea el **banco en USD** (Ajustes → Bancos); los saldos van aparte, en *Otras monedas* |
| Comprar dólares | **Mi dinero → Bolsillos → Convertir divisas**: cantidad, tasa que dio el banco y comisión |
| Que me avisen los pagos en el calendario | **Ajustes → Recordatorios** |
| Usar otra hoja o volver a una copia | **Ajustes → Mi cuenta → Usar otra hoja** |
| Reportar un problema | **Ajustes → Registro de errores → Copiar el registro** |

## Si algo no cuadra
- **Cuadrar** la cuenta: Moni te muestra la diferencia y puede dejar un ajuste.
- **Ajustes → Diagnóstico** si una pantalla falla.
- **Ajustes → Respaldos** para tener una copia.
