# Guía rápida de Moni

**Una idea:** tu dinero está en **cuentas**; cada cuenta se divide en **bolsillos** (casa, mercado, ocio…). Cada peso que entra o sale se anota en un bolsillo, y los saldos se calculan solos.

## Lo de cada día
| Quiero… | Hago… |
|---|---|
| Anotar un gasto | **Inicio → Gasto** (o el botón **Registrar**): valor, bolsillo, listo |
| Anotar un ingreso | **Inicio → Ingreso** |
| Mover dinero de un bolsillo a otro | **Inicio → Mover dinero** |
| Ver cuánto queda | Pestaña **Bolsillos** |
| Pagar la luz, el agua, Netflix… | **Inicio → Pagar servicios** → toca el cobro → *Registrar el pago* |
| Me equivoqué | Toca **Deshacer** en el aviso, o anula el movimiento desde su detalle |

## Lo de cada mes
1. **Presupuesto → Generar** el mes desde tu plantilla.
2. **Más → Nómina → Registrar** lo que te llegó y repartirlo a tus bolsillos.
3. **Deudas →** tarjeta → **Pagar extracto**; créditos → **Pagar cuota**.
4. **Bolsillos → Cuadrar** cada cuenta con lo que dice tu banco.

## Si algo no cuadra
- **Cuadrar** la cuenta: Moni te muestra la diferencia y puede dejar un ajuste.
- **Ajustes → Diagnóstico** si una pantalla falla.
- **Ajustes → Respaldos** para tener una copia.

> ¿Dudas con una palabra? Mira el [Glosario](GLOSARIO.md). Todas las pantallas están en el [Manual de usuario](MANUAL_USUARIO.md).
