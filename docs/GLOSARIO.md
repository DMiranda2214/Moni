# Glosario

| Término | Significado |
|---|---|
| **Banco** | Quien tiene tu dinero: un banco o una billetera (Nequi, Nu…) |
| **Cuenta** | Una cuenta en un banco: billetera, débito, ahorro u otra |
| **Bolsillo** | Una parte de una cuenta con un destino (Casa, Mercado, Ocio). Si una cuenta **no permite bolsillos**, tiene uno solo, interno, y se ve como la cuenta |
| **Saldo de apertura** | Lo que había en un bolsillo al empezar (31/12/2026). Después queda fijo |
| **Saldo** | Apertura + todo lo que entró y salió (sin contar lo anulado) |
| **Movimiento** | Un gasto, ingreso, ajuste o traslado. Los traslados son dos movimientos que suman cero |
| **Anular** | Quitar un movimiento sin borrarlo; se puede restaurar |
| **Cuadrar** | Comparar el saldo de Moni con el del banco y, si quieres, dejar un ajuste por la diferencia |
| **Ajuste** | Movimiento que corrige una diferencia (puede ser negativo) |
| **Presupuesto** | Lo que planeas gastar en un mes, por renglones |
| **Plantilla** | La lista base de renglones, de la que se genera cada mes |
| **Escenario** | Una plantilla alternativa (por ejemplo, Normal y Contingencia) |
| **Plan / Real** | Lo planeado / lo realmente registrado en ese renglón |
| **Renglón** | Una línea del presupuesto: Gasto, Cuota, Ahorro o Fondo |
| **Ahorro (de un renglón)** | Plan − Real, solo cuando el renglón está pagado |
| **Fondo** | Bolsillo para una meta (viaje, regalos…) |
| **Tarjeta de crédito** | Compras que pagas después, en el extracto |
| **Reserva (de una tarjeta)** | Bolsillo donde apartas lo que ya sabes que vas a pagar de esa tarjeta |
| **Extracto** | Las compras de un período de la tarjeta; se paga completo |
| **Fuente (de una compra)** | De dónde sale el dinero: *Personal* (se completa al pagar el extracto), *Presupuesto* y *Guardar* (apartan ya a la reserva, desde el bolsillo del renglón o el personal) u *Otro* |
| **Crédito de autopago** | Un préstamo que te haces a ti: sale de una cuenta de ahorro y lo devuelves en cuotas; cada cuota vuelve al ahorro |
| **Amortización francesa** | Cuota fija; al principio pagas más interés y al final más capital |
| **Abono extra** | Pagar más que la cuota: la cuota y la tasa no cambian, **baja el plazo** |
| **Deuda con el ahorro** | Lo retirado "para gastos" y no repuesto, más el saldo de tus créditos de autopago |
| **Rendimiento** | Interés ganado en una cuenta de ahorro; la **retención** y el **GMF (4x1000)** lo descuentan |
| **Nómina** | Tu salario del mes: devengos menos deducciones = neto |
| **IBC** | Ingreso base de cotización (sobre el que se calculan salud y pensión) |
| **FSP** | Fondo de Solidaridad Pensional (1 % del IBC desde 4 SMMLV) |
| **SMMLV** | Salario mínimo mensual legal vigente |
| **Prima / Cesantías** | Prestaciones: prima en junio y diciembre; cesantías se consignan en febrero y sus intereses se pagan en enero |
| **Suscripción** | Cobro fijo que se repite (streaming, música) |
| **Servicio** | Cobro recurrente de valor variable (luz, agua, internet) |
| **Datos de demostración** | Información ficticia para explorar la app; se borra sin tocar lo real |
| **Arranque** | El paso de la prueba al uso real: saldos de apertura, fecha de inicio |
